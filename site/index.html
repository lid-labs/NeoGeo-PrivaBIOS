Features

Everything in one chip

Why

Why another BIOS?

UniBIOS is the reference on the Neo Geo, and Razoola's work has served players for two decades. Sprixe BIOS takes a different path: a BIOS written from scratch, GPL-3.0, with its whole source open to anyone who wants to read, fix or change it.

  • Autofire as a setting: A, B, C and D one by one, at 10, 15 or 30 shots per second, remembered for each game.
  • Game settings changed from the in-game menu, during play.
  • Settings of a game that has never been launched: the editor shows its defaults and saves a clean entry.
  • A boot screen drawn only with the BIOS font, nothing from the cartridge's graphics.
  • No continue and silent demo for the whole cabinet.

It is a young project: a beta for MVS boards, with a growing cheat list (1,709 for 154 games), tested on one real board so far. Your reports shape what comes next.

Method

How it was made

Coding agents wrote the code, from contracts drawn by observing the original BIOS running, copying no SNK or UniBIOS code (one incident is on record). Nobody has to take that output on trust: every function a player sees has a test scene under MAME, judged on picture or sound, and every scene is proven by planting a bug it must catch. MAME is not a board, so real-hardware reports decide the rest. The full method.

Install

Two ways to run it

On an MVS board

  1. Build the image.
  2. Burn it on a 27C1024.
  3. Swap it with the BIOS chip.
  4. Keep the original.

In MAME

  1. Build the image.
  2. Replace sp-s2.sp1 in your romsets.
  3. Run with -bios euro.

This is a beta. Before swapping chips, write down your board's settings and keep the original chip. Under MAME, moving from the SNK BIOS or UniBIOS 4.0 to Sprixe BIOS and back left the backup RAM's game data intact, with one game and no setting changed. That was not measured on a real board, nor after changing settings here, so treat scores and settings as things you could lose.

FAQ

Questions

Does it run on my board?

Tested on a real MV-2F, and on the MV-6F under MAME. Other boards are untested: tell us how it goes.

And on an AES console?

Not yet. It has an AES mode for MVS boards only.

Does autofire work in every game?

No. 89 of 164 games see it fully; games that read the joystick themselves never do.

Can I go back to my old BIOS?

Yes. Keep the original chip and swap it back.
