Install

Two ways to run it

On an MVS board

  1. Burn it on a 27C1024.
  2. Swap it with the BIOS chip.
  3. Keep the original.

In MAME

  1. Replace sp-s2.sp1 in your romsets.
  2. Run with -bios euro.
FAQ

Questions

Does it run on my board?

Tested on a real MV-2F, and on the MV-6F under MAME. Other boards are untested: tell us how it goes.

And on an AES console?

Not yet. It has an AES mode for MVS boards only.

Does autofire work in every game?

No. 89 of 164 games see it fully; games that read the joystick themselves never do.

Can I go back to my old BIOS?

Yes. Keep the original chip and swap it back.
